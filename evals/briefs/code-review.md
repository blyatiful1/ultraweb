# Brief: B2B developer tool (code review)

## Prompt

We make Diffnote, a code review tool that groups a pull request into reviewable steps and flags the risky hunks so reviewers stop skimming. It plugs into GitHub and GitLab. We sell to engineering managers and staff engineers at companies with 50 to 500 developers. I need a marketing site: what it does, how it works, pricing for three plans, security information, and a way to book a demo or start a free trial.

## Strong result must show

- The product shown working (real-looking diff UI, steps, flags), not abstract icons.
- A clear explanation of how it works in under a minute of reading.
- Pricing with three plans that are comparable at a glance, and honest limits.
- Security section a buyer could forward to their security team.
- Credible proof without invented customer logos or fake testimonials presented as real.
- Distinct identity: it should not read as the default dark-mode SaaS template.

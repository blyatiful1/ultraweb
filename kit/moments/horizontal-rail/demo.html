Horizontal rail

Scroll down. The row below moves sideways while the page moves down.

Six facts about this rail

  • 01

    Sticky

    The section is tall. Inside it, the rail sticks to the top of the screen.

  • 02

    Translate

    Vertical scroll progress becomes a sideways translate, measured from real widths.

  • 03

    Keyboard

    Tab to any card. If it is off screen, the page scrolls to where it is visible.

  • 04

    Native

    Native scroll speed and direction are never changed. Nothing is intercepted.

  • 05

    Phones

    On phones and with reduced motion this is a plain scroll-snap strip with buttons.

  • 06

    No script

    Without JavaScript the same markup is that same native strip.

After the rail

Normal page flow resumes here, with no jump at the end of the sticky range.

shader-orb

A raymarched object drawn by a single fragment shader: no meshes, no textures, no libraries. It stands in for a 3D hero object when a site has no 3D assets. Scroll to see it turn and change shape with the section.

An object made of distance

Every pixel marches a ray toward a signed-distance shape and lights it with diffuse, specular and a fresnel rim in the page's primary and accent colours. The object rotates slowly, leans toward the pointer and turns as the section scrolls past.

Without WebGL, under reduced motion or with JavaScript off, a CSS sphere drawn from the same tokens stays in its place.

Below the object the page continues. The render loop stops when the object leaves the screen or the tab is hidden, and its resolution drops automatically when frames take longer than about 20 ms.

Pinned chapters

Scroll down. The media column stays in view with CSS sticky and changes to match the chapter crossing the middle of the screen.

01

The column stays put

The left column uses position: sticky. Nothing is pinned by script, so native scrolling is never touched.

An observer picks the chapter

An IntersectionObserver watches a line across the middle of the viewport and marks the chapter that crosses it.

03

The progress list is real links

Each item below the media is an anchor to its chapter, so keyboard and anchor navigation work.

04

Phones get a stack

Under 900px wide, with reduced motion, or without JavaScript, each chapter shows its media above its text.

After the chapters

Normal page flow resumes here. The media column leaves with the last chapter, with no jump.
